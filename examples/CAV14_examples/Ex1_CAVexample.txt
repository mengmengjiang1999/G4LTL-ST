## Simple numerical arbitor for two clients, together with error signaling
## One can directly perform synthesis by "Advanced -> Numerical LTL synthesis", but this is slow.
## Alternatively, select "Advanced -> Analyze specification grouping" to see how can the spec be partitioned.
## Then perform synthesis on each subspec. The overall time is much faster.
## 
ALWAYS ({(a)+(b)>3} -> NEXT (grant1))
ALWAYS ({(2*a*a)+(2*b*b)<7} -> NEXT (grant2))
ALWAYS (!(grant1 && grant2))
ALWAYS (error -> t1.start)
ALWAYS (error -> (light && NEXT (light UNTIL t1.expire)))
ALWAYS (ALWAYS !error -> (EVENTUALLY ALWAYS (!light && !t1.start)))

INPUT  a([0;4]), b([0;4]), error
OUTPUT grant1, grant2, light
TIMER t1(10s)
